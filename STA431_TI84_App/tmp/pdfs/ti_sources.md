# TI-84 Plus CE command checks (October 27, 2026)

- [TI-84 Plus CE Reference Guide](https://education.ti.com/download/en/ed-tech/0E32ECD55D084B2EAE7632510BC25FC0/4C0D8E4ED84C4182BC94F8375DEC4E0A/TI84_Plus_CE_ReferenceGuide_EN_GB.pdf): Classic `nDeriv(expression,variable,value[,H])`, printed p57/PDF page61; `seq(expression,variable,begin,end[,increment])`, printed p75/PDF79; `sum(list[,start,end])`, printed p82/PDF86; `1-Var Stats [Xlistname,freqlist]`, printed p87/PDF91. Official syntax supports list operations and calculators' own comparison operators.
- [TI Solution34694](https://education.ti.com/en/customer-support/knowledge-base/ti-83-84-plus-family/product-usage/34694): Classic `fnInt(expression,variable,lower,upper[,tolerance])`; numerical real-valued integration; MATH>9, templates in MathPrint.
- [TI Solution34918](https://education.ti.com/en/customer-support/knowledge-base/ti-83-84-plus-family/product-usage/34918): numeric derivatives only; MATH>8; explicit absence of native symbolic manipulation.
- [TI Solution34473](https://education.ti.com/en/customer-support/knowledge-base/ti-83-84-plus-family/product-usage/34473): sigma_x^2 population variance versus Sx^2 sample variance; standalone `variance(` sample-variance command.

Commands are documented, with arithmetic independently calculated. No physical device run is claimed. No downloaded app or program is required or modified. For integration of a joint density, reduce the inner integral by hand before one-dimensional fnInt.

Coverage: normalization; joint/marginal/conditional PMF/PDF; CDF conversion and rectangle identity; integration regions; reliability words; independence; expectation and LOTUS; raw/central/product moments; transformed variance; MGF convergence/moments/uniqueness/affine transforms/sums; covariance/correlation; one and two linear combinations; conditional first/second moments and total expectation/variance; TI lists, seq/sum, comparison masks, fnInt, nDeriv, sigma_x vs Sx.
